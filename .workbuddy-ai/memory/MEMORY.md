# 项目长期笔记

## 项目
星陨战纪 Starfall v0.1 —— 从线上单文件构建恢复的网页 5v5 MOBA（Three.js + WebAudio，全程序化美术音效）。
仓库：`G:/github/olo`。结构见 README：`src/`（44 个 ES 模块，可编辑）、`modular/`（开发入口）、`dist/`（构建产物）、`_recover/`（原始 bundle + 格式化单文件）、`tools/`（analyze/split/scc/build）。

## 用户偏好
- **后台任务要静音且尽量少占用**：需要看渲染结果时用一次性 `chrome --headless --screenshot`，不要开长驻 CDP 会话；浏览器实例一律加 `--mute-audio`；本地服务器只在验证期间起，用完立刻停，不挂着；长时间任务先说明耗时和资源占用再跑。
- 中文交流。
- **别为了验证一个已经能看到的结论反复跑离线分析**：直接出截图看，比推导数值快得多也省额度。用户对额度消耗敏感，长循环先停手问一句。

## 关键经验：外部骨架蒙皮
- 杯杯菇的 GLB 是 **70 个互不相连的碎片**，撕裂只发生在同一碎片内部 —— 同一碎块的顶点被分到不同骨骼就会裂。
  **逐顶点**独立选骨骼对是错的；必须让"碎块内权重是位置的连续函数"（纯几何权重天然满足）。
- 权重做法：按连通块判定骨骼族 → 每块只允许本族骨骼 → `1/距离²` 取前二。见 `tools/reweight.mjs`。
- `bindQ[root] = Rx(-90°)`（模型 Z 轴朝上）。**要让某个朝向在旋转中不变，就绕那条法线轴转。**
- 侧滚最终定案（用户确认）＝**放平横躺侧滚**：`add(rootJ,0,90,0)` 把身体放平成水平（头转成朝侧向、肚子仍朝前），
  再 `add(rootJ,0,0,ang)` 绕头脚轴整圈滚；`move(rootJ,-1.04,1.02,0)` 让身体居中、最低点贴地。
  `r_max=1.023`、身体沿轴质心 `1.038` 由 `tools/_rollsize` 类脚本量的。
  走过的弯路：①`Rx(90)`+绕头脚轴自转 = 头顶朝前钻地；②绕前进轴侧手翻 = 肚子朝前但会浮空/像转硬币。

## 关键经验：外部 GLB 的贴图（"白模"就出在这）
- **占位图必须和真实贴图同尺寸。** three 的 `texStorage2D` 是不可变存储：第一次上传按占位图尺寸分配，
  之后换 `tex.image` 只走 `texSubImage2D`，尺寸对不上整张被丢弃 → 永远显示占位色。
  1×1 占位 + 512×512 真图 = 经典白模。生成器把真实宽高读出来写成 `TEX_W/TEX_H`。
- **网格模块必须在加载时预热解码**：`setTimeout(() => heroMap(), 0)`。少了它，选将台会在解码完成前
  把立绘渲染进 `j1` 缓存并永久保留。新增英雄时 `32-ui.js` 的 `MAP_HEROES` 也要登记。
- 排查：运行时把 `uMapOn` 置 0 —— 画面变纯白说明贴图本来就在正常工作；不变说明没生效。
  `gl.getUniformLocation(prog,'x') === null` 表示该 uniform 被优化掉（源码里没用到），
  能立刻区分"值不对"和"源码不是我以为的那份"。
- `herocheck` 有两条静态断言守这个（预热行 + 占位尺寸），别删。


## 关键经验：把手持武器挂到外部骨架上（"柄方向怎么摆都不对"就出在这）
- Tripo 骨架的手骨局部轴：**X = 掌背→掌心、Y = 腕→指尖、Z = 拇指→小指**。
  拳头是**沿局部 Z 的握孔**（手指卷起来抱住的那根轴）。
- 所以武器柄轴必须写 **+Z**，并且顶点整块写在**手骨局部坐标**里（外面套 `t.g(handMatrix(...))`）。
  按世界坐标摆"竖直的柄"必然错：世界 +Y 换算到局部是 `(0.44,-0.90,0)`，和手指只差 26°，
  看着像一根竖直杆粘在手上，而不是被手握住。牛伟的斧头为此被骂了三四次。
- 待机想让柄竖起来，再给手腕加 `HAND_ROLL = 90`（绕手骨 X 轴翻），把握孔从朝前转成朝上。
  动画状态里 `play()` 会覆盖腕部四元数，那个 roll 加不进去也不该加。
- 单骨 `weight=1` 刚性蒙皮 = 任何姿势下都攥在手里，不会脱手。
- **查朝向/角度优先用离线 FK 算**（读 `bindWQ` + 片段关键帧，几秒出结果），
  别为了看一眼方向去开无头浏览器截图 —— 后者贵一个数量级。
- `herocheck --crop=x,y,w,h,scale`：战场相机固定俯视，英雄大致钉在屏幕 `(350,170)`，
  用这个抓手部特写。
