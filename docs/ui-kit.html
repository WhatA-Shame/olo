操作说明

EscTabQWERPASDFGBJ空格
  • 移移动W A S D 或方向键；鼠标右键点地面寻路移动
  • 攻普攻空格 / J 自动选择目标；左键或右键点敌人指定攻击
  • 技技能Q 一技能 · E 二技能 · R 大招：按下显示指示器，松开朝鼠标位置施放；Esc / 右键取消
  • 通通用技能F 闪现(朝鼠标) · G 疗伤 · B 回城
  • 界界面Tab 按住看战况 · P 商店 · Esc 设置 / 暂停
  • 1摇杆左下区域按住拖动，控制英雄移动
  • 2普攻按住连续攻击，自动选择最合适的目标
  • 3技能轻点 = 智能施法；按住拖动 = 手动瞄准，松手施放；拖到「取消」区松手则取消；原地长按查看技能说明
  • 4通用技能闪现(可拖动选方向) · 疗伤 · 回城
  • 5小地图点按并拖动可观察战场，松手回到英雄
  • 6商店金币够了会自动买推荐装备；想自己挑就点开商店(关掉自动出装后，钱够时这里会弹出一键购买)
  • 7战况 / 暂停右上角两个按钮：看双方战况、暂停与设置

图上的记号和对局里的小地图是同一套

  • 怎么赢摧毁敌方水晶就赢。你在左下角的蓝色方，敌方水晶在右上角。
  • 推塔上、中、下三条路，每条路按 一塔 → 二塔 → 高地塔 的顺序拆；拆掉任意一路的高地塔，才打得动水晶。塔先打小兵，跟着小兵进塔。
  • 补兵给小兵最后一击拿全额金币，只站在旁边只有约 35%。金币够了会自动买推荐装备。
  • 蓝buff野区的大野怪。打掉它，70 秒内技能冷却更短、回蓝更快。
  • 红buff野区的大野怪。打掉它，70 秒内普攻附带灼烧和减速。
  • 河道巨龙左上河道，2:00 刷新。打掉它：全队每人 +90 金币、+160 经验。它会吐息：看到地上的扇形预警就走出去。
  • 星陨巨灵右下河道，4:30 刷新。打掉它：全队 80 秒内伤害 +15%、持续回血、小兵更强(80 秒一过就没了，趁这会儿推塔)。
