## 把单文件 bundle 重构成 44 个 ES 模块

用户要求「拆成模块化结构」，方便后续用 AI 加英雄/装备。

- 关键结论：原 bundle 是单作用域脚本（1690 顶层语句 / 3044 绑定 / 无 import），不能按行硬切。
- 做法（`tools/analyze.mjs` → `tools/split.mjs`）：
  1. babel 解析每条顶层语句的声明绑定与引用，区分初始化期引用 / 函数体延迟引用；
  2. 跨语句「写」引用强制同模块（ESM 给导入绑定赋值会 TypeError）；
  3. 按**全量引用**拓扑排序（Kahn + 最小原始下标优先）→ 跨模块引用永远指向更早模块，天然无 TDZ、无循环导入；
  4. 按 70KB 顺序切块 → 44 模块（中位 64KB），语义标签 three/render/audio/ui/data/vfx/ai/core。
- 依赖图 SCC 只有 8 处（15 条语句互引），所以合并代价极小。全量依赖图基本是 DAG 是这次能干净拆分的根本原因。
- 三个入口：`index.html`（原始基准，勿改）、`modular/index.html`（模块版，需服务器）、`dist/index.html`（esbuild 重新打包的单文件）。
- `tools/build.mjs` 用本地 esbuild 把 src/ 重新打包回单文件；注意 execFileSync 调 npx.cmd 在 Windows 会 EINVAL，必须用 esbuild 的 JS API。
- 验证：标题/选将/战场逐项与基准一致，45 秒后计时器同为 00:16、金币 75 vs 76。
- 坑：Chrome 会缓存 ES 模块，改完必须 CDP `Network.setCacheDisabled` 或换 profile，否则会看到旧的报错。
- 踩过的坑：`fs.rmSync` / `os.rmdir` 被安全删除 shim 拦截（ETIMEDOUT），生成脚本改成覆盖写入；清理目录用 `git rm` / `git clean -fd` 可行。
- 提交：1d777d5（模块化）、77659e4（移除 dev 入口）。

## 杯杯菇 v3：抄 ququfeiche 的体型 + 侧倒平滚（提交 90422c3）
- 参考实现在 `G:/github/ququfeiche/src/core/baseEntities.ts:9190` 起（`杯杯菇模型`），
  轮廓点在 9560 附近：平底(0.45) → 肥肚(0.93@-0.34) → 收腰(0.61) → 菌褶(褶中/褶缘) → 伞盖(帽半)，km=1.28。
  四肢是 CapsuleGeometry 小肉柱：臂 pivot ±0.86*km、腿 pivot ±0.36*km@-0.74*km。
- 滚动做法：外层 `翻滚轮枢.rotation.x = 翻滚角`，内层 `侧倒枢.rotation.z = 侧倒权*π/2`，
  即 R = Rx(滚) * Rz(90°)；中心高抬到 `滚筒贴地半径 = max(1.14, 0.94*胖度+0.2)*km`（等于伞盖半径）。
  本引擎对应写法：`R.rot(i.hips, 角度, 0, 90)` + `R.move(i.hips, 0, 抬升, 0)`。
- `R.rot` 是四元数直接覆盖（y1 生成 qx*qy*qz，角度单位是度）；`R.move` 是叠加位移。
- 横向胶囊 `t.limb` 渲出来是木棍色（法线问题），短肢改用多个 `t.ball` 拼。

  1. `tex.flipY = false` —— glTF UV 原点在左上，three 默认 flipY=true，症状是贴图碎成色块（不是 UV 传错）。

  把旋转中心从脚底挪到肚子中心（否则绕脚插地）。

  或把网格按关节拆开，暂时不值得。
- 引擎侧契约（15-render-4.js / 26-core-5.js）：`pose.q` 存**绝对局部四元数**，静息态必须填 `HR.bindQ` 而不是单位四元数；
  `rig.bind` 全零；动画每骨 7 个浮点 = pos3 + quat4（**没有 scale**）；`pose.t` 是叠加在绑定局部位移上的增量。
- **侧滚轴的正确解**（推翻上面 v4 的结论）：`R.add(root, 90, 角度, 0)`。
  `y1(x,y,z) = Rx·Ry·Rz`（右边先作用），所以「先 Rx(90) 放倒、再绕自身头脚轴 Ry 转」= `Rx(90)·Ry(角度)`。
  放倒后伞盖变成竖立圆盘 = 轮子，绕头脚轴转 = 轮胎滚动。
  之前 `add(角度,0,90)` 是绕前进轴自转（烤串），而且 `move(root,0.98,0.95,0)` 的前向 0.98 导致浮空。
  抬升量按绑定世界包围盒算：`y∈[0,2]、z∈[-0.81,1.09]`，Rx(90) 后 `y'=-z`，所以抬 1.05、沿 Z 平移 -1 回中心。
- `fire` 片段几乎是静止持势（全片段最大位移 0.04），持续喷吐时另叠高频抖动（chest/head/root）避免僵住。
