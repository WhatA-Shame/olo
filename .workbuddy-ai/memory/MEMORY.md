# 项目长期笔记

## 项目
星陨战纪 Starfall v0.1 —— 从线上单文件构建恢复的网页 5v5 MOBA（Three.js + WebAudio，全程序化美术音效）。
仓库：`G:/github/olo`。结构见 README：`src/`（44 个 ES 模块，可编辑）、`modular/`（开发入口）、`dist/`（构建产物）、`_recover/`（原始 bundle + 格式化单文件）、`tools/`（analyze/split/scc/build）。

## 用户偏好
- **后台任务要静音且尽量少占用**：需要看渲染结果时用一次性 `chrome --headless --screenshot`，不要开长驻 CDP 会话；浏览器实例一律加 `--mute-audio`；本地服务器只在验证期间起，用完立刻停，不挂着；长时间任务先说明耗时和资源占用再跑。
- 中文交流。
- **别为了验证一个已经能看到的结论反复跑离线分析**：直接出截图看，比推导数值快得多也省额度。用户对额度消耗敏感，长循环先停手问一句。

## 关键经验：外部骨架蒙皮
- 杯杯菇的 GLB 是 **70 个互不相连的碎片**，撕裂只发生在同一碎片内部 —— 同一碎块的顶点被分到不同骨骼就会裂。
  **逐顶点**独立选骨骼对是错的；必须让"碎块内权重是位置的连续函数"（纯几何权重天然满足）。
- 权重做法：按连通块判定骨骼族 → 每块只允许本族骨骼 → `1/距离²` 取前二。见 `tools/reweight.mjs`。
- `bindQ[root] = Rx(-90°)`（模型 Z 轴朝上）。**要让某个朝向在旋转中不变，就绕那条法线轴转**：
  侧滚 = 绕模型 Y 转（`R.add(rootJ,0,angle,0)`），肚子始终朝前进方向；先 Rx(90) 再自转会变成头顶朝前钻地。
