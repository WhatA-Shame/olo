## 把单文件 bundle 重构成 44 个 ES 模块

用户要求「拆成模块化结构」，方便后续用 AI 加英雄/装备。

- 关键结论：原 bundle 是单作用域脚本（1690 顶层语句 / 3044 绑定 / 无 import），不能按行硬切。
- 做法（`tools/analyze.mjs` → `tools/split.mjs`）：
  1. babel 解析每条顶层语句的声明绑定与引用，区分初始化期引用 / 函数体延迟引用；
  2. 跨语句「写」引用强制同模块（ESM 给导入绑定赋值会 TypeError）；
  3. 按**全量引用**拓扑排序（Kahn + 最小原始下标优先）→ 跨模块引用永远指向更早模块，天然无 TDZ、无循环导入；
  4. 按 70KB 顺序切块 → 44 模块（中位 64KB），语义标签 three/render/audio/ui/data/vfx/ai/core。
- 依赖图 SCC 只有 8 处（15 条语句互引），所以合并代价极小。全量依赖图基本是 DAG 是这次能干净拆分的根本原因。
- 三个入口：`index.html`（原始基准，勿改）、`modular/index.html`（模块版，需服务器）、`dist/index.html`（esbuild 重新打包的单文件）。
- `tools/build.mjs` 用本地 esbuild 把 src/ 重新打包回单文件；注意 execFileSync 调 npx.cmd 在 Windows 会 EINVAL，必须用 esbuild 的 JS API。
- 验证：标题/选将/战场逐项与基准一致，45 秒后计时器同为 00:16、金币 75 vs 76。
- 坑：Chrome 会缓存 ES 模块，改完必须 CDP `Network.setCacheDisabled` 或换 profile，否则会看到旧的报错。
- 踩过的坑：`fs.rmSync` / `os.rmdir` 被安全删除 shim 拦截（ETIMEDOUT），生成脚本改成覆盖写入；清理目录用 `git rm` / `git clean -fd` 可行。
- 提交：1d777d5（模块化）、77659e4（移除 dev 入口）。

- 提交 2344c25。紫伞盖蘑菇，Q 持续加速旋转冲刺（撞人击飞）、E 锥形孢子粉雾（伤害+减速）、R 蓄力跳跃（警示后落地击飞）。

- **音效命名坑（关键）**：模拟层发的 `fx` 事件键是 `mushroom_s2_spray`，音频层 `onFx` 查的是 `fx_` + 键。漏注册会在 `at()` 里读 `undefined.range` → 整局崩「出了点状况」，而且异常被游戏循环 try/catch 吞掉，`Runtime.exceptionThrown` 抓不到。定位方法：CDP `Debugger.setPauseOnExceptions("all")` 在异常点暂停取调用栈。
- 已给音频 `at()` / `play()` 加缺表兜底：漏注册只静音不崩。
- 贴花 `Xt.cone` 的 `params(半角, 内半径比例)`：内比例传 1 会压成零宽度，看起来「没特效」；传 0.12~0.35 才是可见的扇形。
- 无头环境（`--disable-gpu`）帧率极低，0.3~0.5 秒的短特效经常一帧都没渲染就过期，截图验证短特效要临时把 duration 调长到 2 秒确认，再改回来。
